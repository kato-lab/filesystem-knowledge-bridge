# 登録専用モデル作成手順

## 目的

登録専用モデルを作成し、Register MCP のみ利用できるようにします。

------------------------------------------------------------------------

# 1. モデル作成

1.  管理(Admin) → Models
2.  Create Model
3.  Base Model を選択
4.  名前を入力

例

    Knowledge Register

------------------------------------------------------------------------

# 2. Tool 設定

Knowledge Register モデルに

-   list_incoming
-   register_incoming_project
-   reindex_stored_project

のみ追加します。

Read MCP の Tool は追加しません。

------------------------------------------------------------------------

# 3. モデルパラメータ

  項目          推奨値
  ------------- --------
  Temperature   0.0
  Reasoning     Low

------------------------------------------------------------------------

# 4. システムプロンプト

    あなたは filesystem-knowledge-bridge の登録専用アシスタントです。

    利用できる Tool は

    - list_incoming
    - register_incoming_project
    - reindex_stored_project

    のみです。

    登録前には候補一覧を確認してください。

    通常の検索やプロジェクト内容の説明は行わず、
    検索専用モデルを利用するよう案内してください。

------------------------------------------------------------------------
